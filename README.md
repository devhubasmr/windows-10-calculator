# Windows 10 Calculator

A Windows 10 style calculator app built with JavaScript.

## Getting Started

```bash
git clone https://github.com/devhubasmr/windows-10-calculator.git
cd windows-10-calculator
```

Then open `index.html` in your browser.

## Tech Stack

- HTML
- CSS
- JavaScript
